# hxwl-03 岩土钻孔编录

土样试验结果落地层平台：试验结果按钻孔与取样深度自动归属地层，异常记录挂起，
地层指标汇总后由负责人编报锁定，锁定后新结果走带原因的修订流程。

## 技术栈

React + Vite + TypeScript + CSS，数据保存在浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 测试与构建

```bash
npm test        # vitest：校验规则、汇总计算、锁定/修订流程
npm run build   # 生产构建
```

## 功能

- **钻孔与地层**：建孔、划分地层区间（层顶/层底埋深），同孔区间不允许重叠
- **结果录入**：填土样编号、深度、含水量、密度、液限、塑限、内摩擦角、黏聚力，
  实时预览落点；液限 ≤ 塑限或深度压在地层分界线上的记录自动挂起，
  挂起列表点明哪孔、哪条记录、什么原因
- **挂起记录**：修正后重新提交（仍不合格则继续挂起保留），或删除
- **地层汇总**：同一地层各指标平均值、塑性指数 IP、液性指数 IL 及状态分级；
  六项指标凑齐后负责人才能编入报告并锁定，锁定生成不可覆盖的版本快照
- **修订处理**：锁定后新结果只能另建带原因的修订；负责人可采纳（生成新汇总版本，
  原版本保留）或搁置；修订历史全部可查
- 角色切换（录入员 / 负责人），锁定与修订处理仅负责人可操作
