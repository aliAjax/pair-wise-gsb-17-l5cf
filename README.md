# hxwl-03 岩土钻孔土样试验成果归层

试验结果按孔和深度落到对应地层；挂起、汇总、锁定与带原因修订的完整工作流面板。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 持久化，无后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 业务规则

- 每条记录 8 项：土样编号、深度、含水量、密度、液限、塑限、内摩擦角、黏聚力。
- 提交即按「钻孔 + 深度」落层；**液限 ≤ 塑限** 或 **深度压在地层分界线上**（或超出孔深）时记录挂起，
  页面点明是哪孔、哪条记录（土样编号）、什么原因；挂起记录原样保留，修正后可重新校验落层。
- 同一地层汇总 6 项指标平均值，并由平均含水量/界限含水量计算**液性指数 IL**（附坚硬/硬塑/可塑/软塑/流塑判定）。
- 指标凑齐（6 项有值且 IL 可计算）后，**项目负责人**才能把地层编入报告并**锁定**；编录员无此权限。
- 锁定即对汇总值做版本快照（v1）。锁定后进入的新结果不能覆盖原值，只能由负责人**另建带原因修订**（v2、v3…）；
  全部历史版本（锁定值、修订原因、操作人、时间、所含土样）原样保留。

## 示例数据

- ZK-18：4 个地层 6 件土样，其中 `ZK18-T06` 深度 1.8m 压在 ①/② 分界线上，自动挂起。
- ZK-21：3 件有效土样 + `ZK21-T04`（深度压 ②/③ 分界线 10.4m 且 wL = wP = 17.0，双重原因挂起）。
- 「恢复示例数据」按钮可清空锁定/修订并重置全部记录。
